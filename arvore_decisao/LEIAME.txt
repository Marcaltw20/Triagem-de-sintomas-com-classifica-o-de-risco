ÁRVORE DE DECISÃO – CLASSIFICAÇÃO DE RISCO (TCC 2026)

Requisito: Python 3.9 ou superior (não precisa instalar nenhuma biblioteca).

ARQUIVOS
  arvore_decisao.py      -> a árvore de decisão (o "motor"). É este arquivo que a LLM vai usar.
  teste_manual.py        -> você digita os valores e os sintomas e vê a classificação.
  testes_automaticos.py  -> roda os 80 casos de teste de uma vez (P01-P27 = casos da monografia;
                            P28-P80 = árvore ampliada).

COMO USAR (no terminal, dentro desta pasta)
  python teste_manual.py
  python testes_automaticos.py

USAR DE OUTRO CÓDIGO (ex.: código main ou da LLM)
  from arvore_decisao import classificar_risco
  r = classificar_risco(pas=185, pad=100, fc=88, spo2=97, temp=36.8, sintomas=["falta_de_ar"])
  print(r["cor"], r["motivo"])

INTEGRAÇÃO COM A LLM (futuro)
  - TOOL_SCHEMA: descrição da ferramenta para registrar na API da LLM (function calling).
  - executar_ferramenta(argumentos): recebe os argumentos que a LLM mandar e devolve o resultado em JSON.
  - A LLM só converte a fala do usuário em sintomas; quem decide a cor é a árvore.

COMO A ÁRVORE DECIDE
  Tudo segue o Protocolo de Classificação de Risco baseado no Manchester (Aparecida de
  Goiânia, 2025), citado em cada regra do arvore_decisao.py.
  1. Cada sintoma do CATALOGO tem a cor do discriminador do fluxograma da queixa. São 102
     chaves em 13 grupos (fatores de risco, duração da queixa, neurológico, coração,
     respiratório, digestivo, urinário e reprodutivo, alergia e pele, trauma, olhos/ouvidos/
     nariz/boca, músculos e articulações, saúde mental e geral).
  2. Dor pela escala do protocolo: dor_leve (1-3) verde, dor_moderada (4-6) amarelo,
     dor_intensa (7-10) laranja.
  3. Sinais vitais pela tabela do Anexo III (temperatura pelo Anexo II). Faixa com duas cores:
     vale a mais grave.
  4. Combinações só as do protocolo (choque, choque anafilático, dor precordial, falta de ar
     com SpO2 < 92%, sangramento vaginal na gestação, disúria/dor de garganta com febre), nas
     listas COMBINACOES_*. Gestação: COMBINACOES_GESTACAO [exceção obstétrica].
  5. Fatores de risco não mudam a cor. queixa_antiga (> 7 dias): o que daria verde vira azul.
  6. Vale a cor mais grave; no empate, a regra que vem primeiro (N1 -> N6).
     As demais regras que dispararam voltam em r["outros_achados"]. O NEWS2 é só informativo.
  A ordem completa está no cabeçalho de arvore_decisao.py.

PARA ACRESCENTAR UM SINTOMA OU UMA REGRA
  - Sintoma novo: uma linha no CATALOGO (chave, rótulo, descrição, cor-base), com o comentário
    do fluxograma de onde veio a cor. O prompt da LLM, o teste manual e a tela passam a
    conhecê-lo sozinhos.
  - Combinação nova: uma linha em uma das listas COMBINACOES_*.
  - Acrescente um caso em testes_automaticos.py.

CHAVES DE SINTOMAS ACEITAS
  Veja o CATALOGO em arvore_decisao.py, ou rode:
    python -c "import arvore_decisao as a; print(*a.SINTOMAS, sep='\n')"
